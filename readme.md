# TaskMaster - Sistema No-Code de Gestão de Tarefas (PIT II)

Repositório oficial da documentação e artefatos de suporte do projeto **TaskMaster**, desenvolvido para a disciplina de Projeto Integrado Transdisciplinar II (PIT II).

## 📋 Sobre o Projeto
O **TaskMaster** é uma aplicação corporativa e acadêmica voltada para a gestão eficiente de tarefas, projetos e equipes. Utilizando uma abordagem moderna de desenvolvimento **No-Code**, a solução prioriza a estabilidade de dados, sincronização em tempo real na nuvem e uma experiência de usuário responsiva e intuitiva.

## 🛠️ Arquitetura e Tecnologias
A modelagem do sistema foi planejada seguindo boas práticas de engenharia de software e banco de dados relacional:
* **Banco de Dados:** Google Sheets (estruturado em 3 tabelas principais: `Tarefas`, `Projetos` e `Usuarios`).
* **Plataforma de Desenvolvimento (App):** AppSheet (No-Code Platform).
* **Hospedagem:** AppSheet Cloud Server.
* **Modo de Construção:** No-Code.

## 🚀 Funcionalidades Principais
1. **Quadro Kanban de Tarefas:** Visualização em painel para acompanhamento prático do fluxo de trabalho e alteração rápida de status/prioridade.
2. **Diretório de Projetos:** Módulo dedicado ao gerenciamento e acompanhamento dos projetos ativos e seus responsáveis.
3. **Gestão de Usuários e Autenticação:** Controle de membros da equipe com registro automatizado de autoria nas tarefas.
